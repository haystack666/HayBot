# 浏览器工作台交互原型

打开 index.html 即可预览，无需构建。此原型沿用正式后台的黑白配色、边框、字体和间距，支持明暗主题及手机布局。

## 本轮已完成

- 实时画面为中心；任务进度及自动浏览进度压缩成底部状态栏。
- 任务、互动记录分开切页；设置按分类放进右侧抽屉。
- 接管后展示地址操作、手势和输入工具；主人登录及完成确认流程。
- 进入页面逐项动画检测，通过后自动关闭。页尾提供各异常状态演示。
- 缺少 Node.js：官方下载安装步骤、安装后重检；另区分服务未启动、缺少 Chrome。
- 设置按 Bot 隔离演示，提供私信检查间隔、每日总数和实验性无头模式风险确认。

## 范围

这是审核用静态原型：画面为合成示意，数据、环境检测、任务、互动核验均为模拟；不连接真实 Bot，不发送消息，不安装软件。设置仅保留在本次页面会话。

正式 UI 仍待用户看过原型后再接入。正式 Node.js 启动前检查和便捷启动入口仍待实现，不能把本页的模拟提示当成安装功能已上线。

## 清晰度修复（真实运行时代码）

browser_runtime/src/engine.mjs 已指定 screencast size 为实际视口、JPEG quality 为 90，避免默认将画面长边缩至 800 像素后再放大。保持 CSS 像素输入坐标。

2026-10-29 验证：28 项运行时测试通过；隔离 Chrome 综合测试通过，直接解码推流 JPEG 确认为 1600×900，并覆盖接管、标签页、登录隔离及资料持久化。静态原型已实际检查明暗主题、接管、登录、设置、记录核对、安装场景和 390px 手机布局，无页面脚本错误或横向溢出。

运行时代码尚需重启现有服务才能生效；本轮未重启生产浏览器会话。
