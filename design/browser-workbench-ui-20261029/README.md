# 浏览器工作台交互原型

打开 index.html 即可预览，无需构建。此原型沿用正式后台的黑白配色、边框、字体和间距，支持明暗主题及手机布局。

## 本轮已完成

- 实时画面为中心；任务进度及自动浏览进度压缩成底部状态栏。
- 任务、互动记录分开切页；设置按分类放进右侧抽屉。
- 接管后展示地址操作、手势和输入工具；主人登录及完成确认流程。
- 进入页面逐项动画检测，通过后自动关闭。页尾提供各异常状态演示。
- 缺少 Node.js：官方下载安装步骤、安装后重检；另区分服务未启动、缺少 Chrome。
- 设置按 Bot 隔离演示，提供私信检查间隔、每日总数和实验性无头模式风险确认。

## 范围

这是审核用静态原型：画面为合成示意，数据、环境检测、任务、互动核验均为模拟；不连接真实 Bot，不发送消息，不安装软件。设置仅保留在本次页面会话。

本页仍为模拟原型；用户确认后，正式 UI 和本机 Node.js 启动前检查已接入，见下方「正式接入」。

## 正式接入

原型经用户确认后已接入正式 React 工作台。正式配置沿用最新固定无头要求，不采用原型里的旧实验开关。新增根目录「启动浏览器.command」及 Python 启动检查。运行 Node 前检查安装与版本、缺失时提供官方安装和重试，缺少 npm 依赖时自动准备。安装需要用户操作系统安装器；不会静默提权安装。

正式工作台通过独立 Docker 后台与临时 Chrome 的端到端验收，涵盖设置分类保存、视口画面与拖动、主人登录、隔离、放大、Bot 切换、手机布局、任务详情和退出撤权；48 项前端/运行时测试及 4 项启动器测试通过。browser-workbench-light.png 与 browser-workbench-dark.png 为正式页面的隔离验收截图。

部署验收：8080 容器健康，正式页面环境弹窗自动关闭，设置与记录页可用，390px 布局无横向溢出，无页面脚本错误。正式流解码为 1600×813，与该帧上报的可见视口完全一致；隔离测试页面为 1600×900。高度随 Chrome 当前可见视口变化，不伪造固定尺寸。数据、SQLite 一致性快照、浏览器资料和旧镜像已备份到私有部署目录。
