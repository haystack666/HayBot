# 前端文案审阅

- `index.html`：独立审阅页，默认只看副标题，支持搜索、按页面 / 类型筛选、勾选待删、复制编号、导出。支持明暗主题。不会调用产品 API。正式服务固定地址为 `/assets/copy-review/index.html`。
- `SUBTITLES.md`：只看副标题。
- `INVENTORY.md`：完整清单，包含页面、位置、类型、原文与源码行列。
- `inventory.json`：结构化清单。
- `extract.cjs` / `build_review.py`：从全部前端 JS / JSX 抽取并生成审阅页。

生成日期：2026-10-28。清单反映 Via 初始化版部署后的前端源码；已按 decisions.json 执行指定删除；保留原文和原编号，并标注已删除状态。动态值以〔表达式〕表示，条件分支以 / 分隔。相同文字出现在不同位置时保留不同编号。补充候选允许包含较长按钮名、辅助访问名称和反馈，以免遗漏；其中不是所有项目都属于副标题。旧 QQ 空间页的副标题定义已标注重定向情况。

范围是产品自带界面文案，覆盖折叠区域、设置标签、弹窗、空状态与失败提示。后台返回的执行结果、模型生成内容、用户填写的配置不是前端固定文案，没有复制真实聊天或日记内容。

回复「删除 T001、T012；T020 改成……」即可。勾选在当前浏览器本地保存，需复制编号或导出后交给开发处理。
