# 查看进度 · 并排交互原型

打开 index.html，点击视频下方「查看进度」。桌面端采用左侧视频、右侧进度的并排布局；使用 Grid 轨道动画共同调整宽度，右侧不覆盖视频，没有遮罩，不重新创建视频节点。关闭或 Esc 收起后恢复原布局。

进度区与播放器等高，内容独立滚动，包含任务概况、当前步骤、播放推进和互动记录。模拟下一步仅更新演示内容。页面底部「慢速演示动效」可查看展开和收起过程，支持明暗主题和减少动画偏好。850px 以下放在视频下方，避免挤成两个过窄的区域。

全部画面和数据为合成演示，不连接实际 Bot，不运行任务。此目录是独立 HTML 原型，未修改或部署正式工作台。

已通过浏览器验证：展开/收起、无模态遮罩、视频与进度不重叠、模拟步骤更新、暗色主题，以及 390px 手机布局无横向溢出。
