# 抖音互动边界与验收（2026-10-29）

所有互动均默认关闭。设置入口：浏览器 → 抖音自主浏览 → 设置 → 抖音互动。

- 所有主题都可以发表新评论。标题明确包含 DeepSeek、DS、深度求索时采用 DeepSeek 概率（默认 50%），其他内容默认 15%。同一账号、视频、北京时间日期只抽取一次；获得机会不强制发言。单次和每日新评论额度同时生效。
- 评论回复采用独立每日额度，仅可回复真实回复自己已确认发布评论的用户。记录真实 CID、父 CID、视频 ID 与登录账号，禁止按评论列表序号猜测。已有评论记录支持跨任务回访原视频。
- 点赞无次数额度，保持已赞状态，不执行取消点赞；读真实按钮状态，不以点赞数增长证明成功。
- 私信只回复真实来信。非白名单还必须确认对方关注自己；所有非白名单用户合计受跨任务终身总次数约束。白名单由抖音号、昵称共同匹配真实账号，不占此总额度，同一来信仅回复一次。
- Owner 分享通过抖音分享面板发送真实视频卡片。先核对抖音号、昵称、稳定用户 ID，再读取 Owner 会话作为发送前基线。卡片确认后可发送一条文字与一个站内表情，支持文字、文字配图、仅图。单次和每日分享上限独立配置。未实现任意本地图片上传。
- 互动按登录抖音账号跨 Bot、跨任务去重与计额。单日按 Asia/Shanghai 重置，非白名单私信总额度不自动重置。单次额度按任务计算。
- 提交前写入持久记录；待处理、已确认和结果未知都预占额度。未知结果不重试；服务重启将待处理转为未知。平台明确拒绝释放额度。
- 只有稳定的目标、真实来信/父评论、发送结果证据才能允许或确认操作；页面正文不能授予权限。接管、登录隔离、取消同步撤销操作权。已有人工草稿不覆盖。
- 模型只能取得受限工具和公开证据，不能取得运行时令牌、操作授权 ID、Cookie、签名 URL 或通用 JS 执行能力。

## 已验证

后端策略、配置持久化、同账号跨 Bot 配额、重复发送、未知提交、概率不可重抽、私信资格、白名单同名冒用、独立回复额度与任务结果整合均有测试。

隔离真实 Chrome 页面验收涵盖发布回执校验、真实 mention 标记、点赞幂等、评论回复、草稿保护、未知结果不重发、提交中接管、私信资格、Owner 视频卡片与文字/表情分别确认。正式工作台通过 Docker 中继验收设置、白名单、宽屏、手机布局、拖动、放大、暗黑/明亮、登录隔离与 Bot 切换。

真实抖音页面仅做只读检查：登录账号和抖音号成功识别、当前消息列表稳定用户 ID 识别、实际会话两条来信识别、关注关系和对方抖音号识别、评论编辑器与点赞状态核对。当前消息 ID 与会话身份来自已渲染组件的白名单字段，不通过屏幕位置猜测。实际公开评论、@、点赞、分享和私信尚未做对外发送验收。

## 当前限制

站点组件结构变化时会拒绝不能确认的操作；只看到昵称或分享按钮不代表接收人已核实。站内分享接收人必须在当前面板可被明确识别；不按昵称模糊匹配。无人来信、无真实父评论、无可确认身份时不会主动尝试发送。验证与登录仍由 Owner 接管。未新增后台定时扫描，互动发生在用户启动的抖音任务中。
