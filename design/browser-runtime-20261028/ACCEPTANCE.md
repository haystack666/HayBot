# 浏览器原型验收清单

日期：2026-10-28。当前所有动态实验均为“未执行”。这份清单是下一阶段实施标准，不是通过报告。

## 阶段 2：独立原型

采用单独开发端口、临时资料目录、合成本地网页，不连接正式 Bot、不读取个人浏览器资料、不迁移正式登录态。

| 编号 | 实验 | 必须记录的结果 |
| --- | --- | --- |
| P01 | 依赖与启动 | 锁定 Node/Playwright 版本，记录实际 Chrome 版本和启动参数；核对是否为统一 Headless |
| P02 | 进程隐藏 | 冷启动、重启、弹出新标签、页面对话框和退出过程中均无可见浏览器窗口；实际检查 macOS Dock 和应用切换器 |
| P03 | 持久化与隔离 | 合成 Cookie/localStorage 重启后保留；A/B 资料互不可见；同资料重复启动明确报错 |
| P04 | 采集能力 | 检测 Screencast API，验证 JPEG 解码、尺寸/时间戳；新旧 API 选择与失败原因可诊断 |
| P05 | 实时更新 | 静态页、动画、滚动和本地视频持续变化；记录帧率、延迟、CPU 和传输量；不把录制 fps 当成回调帧率 |
| P06 | 坐标与文字 | 100%/缩放/放大查看、不同宽高比的点击定位；中文输入、选区替换、滚轮和键盘；黑边不触发操作 |
| P07 | 标签与弹窗 | 新标签页自动登记，切换画面一致；关闭活动页后落到有效页面；旧 tab/generation 输入被拒绝 |
| P08 | 网页结构 | 语义按钮、同名元素、iframe、延迟渲染和 Canvas；结构不可读时保留实际可见截图，不虚构目标 |
| P09 | 慢查看端 | 一个/多个查看端、慢接收、断线重连；最新帧优先、内存有界、无输入重放 |
| P10 | 生命周期 | 只关闭原型拥有的进程；崩溃后状态准确、锁可恢复，资料保留；用户日常 Chrome 不受影响 |
| P11 | 容器通路 | 在现有 Docker Desktop 拓扑验证宿主运行时通信；无认证拒绝；记录实际监听地址和访问范围 |
| P12 | 媒体边界 | 本地视频播放进度推进；分开记录字幕、画面、声音能力，声音未实现不能填“有声播放通过” |

P02 是用户的硬要求。无头模式仍有 Dock 图标时不得标记通过；需要继续研究启动形态并保留实测证据，不能修改用户日常 Chrome 应用包来隐藏图标。

阶段 2 只证明基础运行链路。Windows 的任务栏、输入法和进程回收另做平台验收，不能用 macOS 结果代替。

## 阶段 3–4：产品接入

| 编号 | 场景 | 验收条件 |
| --- | --- | --- |
| I01 | 工作台实时查看与放大 | 状态真实、无图片变形、缩放不重开浏览器或重复采集、查看不占操作租约 |
| I02 | 接管抢占 | 接管立即阻断旧任务动作；执行中的不可取消动作记录结果；旧请求不能恢复控制 |
| I03 | Owner 登录 | 登录期间模型观察/QQ截图/诊断不记录凭证，退出后重新观察；普通群友不能要求查看登录画面 |
| I04 | 多 Bot | 资料、标签、画面、任务、Owner、QQ 回传正确隔离 |
| I05 | QQ 两种接入 | NapCat 与官方 QQ 都覆盖自然指令、引用消息、状态、取消、截图和结果通知；收到发送回执才标成功 |
| I06 | 自主探索 | 陌生测试站点能根据目标搜索/比较/调整方向；没有固定选两个即完成的计划模板 |
| I07 | 任务收尾 | 关闭任务临时标签、暂停媒体、释放租约；失败/取消也执行可确认的清理；保留用户指定页面与资料 |
| I08 | 未知写入结果 | 评论提交时断线、接管或崩溃均不自动重复发布；恢复后观察核验，结果仍不明则保留未知 |
| I09 | 生命周期权限 | Bot 停止、归档、账号切换、会话失效后旧操作被阻断，后台画面与控制鉴权一致 |
