## 实际界面操作

在 Codex 内置预览页操作原型，没有为验收打开日常 Chrome 窗口：

1. 页面进入自动检测，环境就绪后检测明细收起。
2. 启动原型 A、接管、打开本地合成网页。
3. 点击实时画面中的输入框，经文字输入通道写入“你好，浏览器运行时验收通过”。
4. 放大画面，按实际显示位置点击保存，实时画面显示“已保存：你好，浏览器运行时验收通过”。
5. Esc 收起；重新连接后接管失效、输入被禁用；重新接管恢复。
6. 本地 Canvas 动画和合成视频持续更新。集成测试单独确认 video.currentTime 推进；没有声音采集能力。

界面截图保存在 `prototype/`。环境检测、主工作区遵循黑白配色并支持深浅主题；停止操作用红色。该页面服务于开发验收，正式工作台尚未接入。
